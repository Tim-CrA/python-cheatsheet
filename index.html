1. Ввод данных и обработка строк

Как запросить у пользователя число, строку или целый массив в одной строке.

Ввод одного целого числа

n = int(input("Введите число: "))

Как использовать: input() ждёт ввода от пользователя в виде строки, а int() превращает её в целое число для математики.

Ввод нескольких чисел из одной строки (map и split)

counts = list(map(int, input().split()))

Как использовать:

  1. input().split() режет введённую строку по пробелам на отдельные кусочки-тексты.
  2. map(int, ...) применяет функцию int к каждому кусочку, превращая их в числа.
  3. list(...) собирает результат в полноценный список.

Удобно, когда массив вводится одной строкой: цены, количество товаров и т. п.

Ввод дробных чисел (цены, координаты)

prices = list(map(float, input().split()))

Как использовать: всё то же самое, но вместо int используется float, чтобы программа понимала числа с плавающей точкой (например, 45.99).

2. Вывод данных

Как вывести результат красиво и без лишних символов.

Красивый вывод массива (распаковка)

a = [5, 8, 12, 3]
print(*a)

Как использовать: звёздочка * перед списком разворачивает его элементы, выводя их в строку через пробел без квадратных скобок и запятых.

Форматированные строки (f-строки)

print(f"День {i + 1}: осадки {a[i]} мм")

Как использовать: буква f в начале позволяет вставлять любые переменные и простые вычисления прямо внутрь текста через фигурные скобки {}.

3. Генерация случайных чисел (random)

Нужен везде, где требуются случайные данные: оценки, погода, числа для тестов.

Подключение модуля

import random

Случайное целое число в диапазоне

x = random.randint(-30, 30)

Как использовать: генерирует число от min до max включительно.

4. Генераторы списков (list comprehensions)

Способ создавать массивы в одну строчку.

Массив со случайными числами фиксированной длины

a = [random.randint(1, 10) for _ in range(25)]

Как использовать: цикл for _ in range(25) повторяется 25 раз, каждый раз создавая новое случайное число. Подчёркивание _ ставится, когда переменная цикла внутри нам не нужна.

Фильтрация элементов (создание нового списка по условию)

b = [x for x in a if x % 2 == 0]

Как использовать: берёт каждый элемент x из списка a, проверяет условие (например, x % 2 == 0 — чётность) и сохраняет в новый список b только то, что подошло.

5. Условия (if, else) и математика

Как программа принимает решения и считает суммы.

Проверка на чётность

if x % 2 == 0:
    print("Чётное")

Как использовать: оператор % находит остаток от деления. Если остаток от деления на 2 равен нулю (== 0), число чётное.

Накопление суммы («копилка»)

total_cost = 0
for i in range(n):
    total_cost += counts[i] * prices[i]

Как использовать: заводим переменную-сумму, равную нулю, а внутри цикла прибавляем к ней новые значения (+=). Типичный приём для расчёта стоимости, суммы или подсчёта элементов.

6. Циклы и индексы

Как перебирать элементы и обращаться к началу и концу списка.

Перебор по индексам (когда важен номер элемента или дата)

for i in range(len(a)):
    print(f"{i + 1} сентября: {a[i]}")

Как использовать: len(a) узнаёт длину массива, а range() генерирует индексы от 0 до len(a) - 1. Так как индексация в Python начинается с нуля, для вывода привычного номера (с 1) пишем i + 1.

Доступ к краям списка

  • Первый элемент: b[0]
  • Последний элемент: b[-1] (отрицательные индексы считают с конца списка)

С таким набором можно решить практически любую школьную задачу на массивы и условия.
