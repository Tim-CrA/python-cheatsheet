Шпаргалка по Python

От основ к спискам и условиям

1. Ввод и вывод данных (input и print)

Позволяет общаться с пользователем: запрашивать данные и выводить результат на экран.

Ввод целого числа

n = int(input("Введите число: "))

Как использовать: функция input() ждёт ввода текста от пользователя в терминале. Обёртка int() превращает этот текст в целое число, чтобы с ним можно было производить математические операции.

Красивый вывод массива (распаковка)

a = [5, 8, 12, 3]
print(*a)

Как использовать: звёздочка * перед именем списка распаковывает его элементы. Python выводит их в одну строчку через пробел, убирая квадратные скобки и запятые.

2. Модуль random (генерация случайных чисел)

Нужен везде, где требуется создать случайные данные: оценки, погода, числа для тестов.

Подключение модуля

import random

Генерация одного случайного числа

x = random.randint(-30, 30)

Как использовать: создаёт случайное целое число в диапазоне от min до max включительно (в примере — от -30 до 30).

3. Генераторы списков (list comprehensions)

Самый мощный и питонистичный способ создавать массивы в одну строчку.

Массив фиксированного размера со случайными числами

a = [random.randint(1, 10) for _ in range(25)]

Как использовать: цикл for _ in range(25) повторяет действие 25 раз. На каждом шаге создаётся случайное число и записывается в список a. Подчёркивание _ используется вместо переменной, когда её значение внутри цикла нам не нужно.

Фильтрация элементов (создание нового списка по условию)

b = [x for x in a if x % 2 == 0]

Как использовать: берёт каждый элемент x из списка a, проверяет условие (if x % 2 == 0 — на чётность) и, если оно истинно, добавляет элемент в новый список b.

4. Условия (if, else)

Помогают программе принимать решения в зависимости от данных.

Проверка на чётность

if x % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")

Как использовать: оператор % находит остаток от деления. Если остаток от деления на 2 равен нулю (== 0), то число чётное.

Проверка диапазона (хорошие отметки)

if x >= 7:
    count += 1

Как использовать: проверяет, больше или равно число семи (включает 7, 8, 9, 10).

5. Циклы (for)

Используются для перебора элементов в списках или диапазонах.

Перебор элементов по значению

for x in a:
    print(x)

Перебор по индексам (когда нужен номер дня или элемента)

for i in range(len(a)):
    print(f"День {i + 1}: осадки {a[i]} мм")

Как использовать: len(a) узнаёт длину списка. range() создаёт последовательность индексов от 0 до len(a) - 1. Поскольку индексация в Python начинается с нуля, чтобы получить привычный номер дня (с 1), мы пишем i + 1.

6. Работа с индексами и срезами

Первый и последний элемент списка, форматированные строки.

Первый и последний элемент

  • Первый элемент списка: b[0]
  • Последний элемент списка: b[-1] (отрицательные индексы в Python считают с конца)

Форматированные строки (f-строки)

print(f"{i + 1} сентября")

Как использовать: буква f перед строкой позволяет вставлять любые переменные или выражения прямо внутрь текста с помощью фигурных скобок {}.

С таким набором можно решить практически любую школьную задачу на массивы и условия.
